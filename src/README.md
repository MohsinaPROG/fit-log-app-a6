# FitLog

## Short Description

FitLog is a responsive workout management web application that helps users explore workouts, view workout details, create a daily workout plan, and save their favorite workouts for later.

## Technologies Used

- Next.js
- React
- TypeScript
- Tailwind CSS
- Lucide React
- REST API
- Git & GitHub

## Key Features

- Browse and search workouts from the workout library
- View detailed information about each workout
- Add workouts to today's workout plan
- Save favorite workouts for later
- Manage and remove workouts from the daily
